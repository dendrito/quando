# Optional home information and private edition

Home display controls live beside the city/timezone label. Day + night and Moon phase are separate offline switches. Moon times are approximate SunCalc calculations for the selected city's civil day, including DST. Nightfall uses the existing configured 8.5-degree or 72-minute calculation; it is not an observation of visible stars. Weekly parashah is separately optional.

Weather is off by default. Enabling it reveals sky/weather pages, switchable by swiping or their text buttons. Requests begin only while the weather page is selected and the app is resumed. MET Norway receives coordinates rounded to two decimal places, not the local GPS fix. Cache expiry, conditional requests, jitter and retry backoff limit traffic; cached forecasts are marked when stale. No hosted proxy or public-scale service guarantee is implemented. Review MET Norway's aggregate 20 requests/second limit, no-SLA terms and current terms before release: https://api.met.no/doc/TermsOfService . Attribution links to CC BY 4.0. Lightning is forecast decoration, not a safety warning. One confined bolt fade per eight seconds; Reduce Motion gives static art.

Matai and Quando Mine offer individually optional Daf Yomi, Rambam one/three chapters, Sefer HaMitzvot, Mishnah and Nach schedules. Daf works offline. Other schedules use date-only Hebcal month requests, cached locally, with attribution and vetted source links. No full learning text is copied. https://www.hebcal.com/api-docs/ . The learning day follows the selected city's civil date.

Quando Mine uses the same source with `--dart-define=QUANDO_EDITION=mine`, Android `--flavor mine`, or `tool/ios_edition.sh mine` before iOS compilation. It combines Matai's home with unrestricted Quando quote/radio choices and retains its own app ID. Restore with `tool/ios_edition.sh quando`. This private edition is not part of public release CI or store publishing. Recovered historical Mine code was not found; no recovered implementation is claimed. Firebase registrations are in the existing project; registration does not verify sign-in, sync rules or device behavior.

New English strings have Portuguese translations and English fallback in the other locale catalogs. Translation review remains a release gate. Tests distinguish source behavior from native installation and hardware verification. No Google OAuth session broker, public Tuya service, paid weather plan or billing was deployed.
